# AnimaHub Classificador Web

Frontend React do MVP single-user.

## Escopo inicial

- Tela de cadastro/edição do perfil único;
- estados de interesse;
- descrição livre sobre formação e experiência;
- tela de concursos em cards verticais;
- busca por cargo ou órgão;
- filtros por estado e situação;
- dados fake locais enquanto a API ainda está sendo integrada.

O perfil é salvo temporariamente no `localStorage` do navegador. A integração com o backend substituirá esse armazenamento quando os endpoints estiverem disponíveis.

## Executar

```powershell
npm install
npm run dev
```

## Build de validação

```powershell
npm run build
```
